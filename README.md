# Password Strength Analyzer

A beginner-friendly Python project that analyzes password strength using regular expressions (Regex).

## Features
- Checks password length
- Detects uppercase and lowercase letters
- Checks for digits and special characters
- Detects common passwords
- Detects repeated characters
- Detects predictable sequential patterns
- Provides personalized improvement suggestions

## Technologies Used
- Python
- Regular Expressions (Regex)

## How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run:

   `python regex.py`

4. Enter a sample password to see the analysis.

## Learning Goals
This project helped me practice Python functions, conditional statements, regular expressions, and basic password-security concepts.

**Note:** This is an educational project. Its strength rating is a basic heuristic, not a guarantee of real-world password security.
